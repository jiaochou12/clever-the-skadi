桌宠设置

API 设置（OpenAI 兼容接口）

常用的还有 https://api.deepseek.com/v1 等，填到 /v1 即可

模型动作

列出模型支持的全部动画；选择"走路"时模型朝一个方向行走，到达屏幕边缘（按模型自身可见范围判断）自动折返；拖动不受限，走丢可在下方点"找回桌宠"
播放一次选中的动画，播完自动回到当前动作
当前动作为"随机动作"时，每隔一段随机时间自动切换一个随机动画；最小间隔大于最大间隔时保存会自动交换

对话框

宽度与高度共同决定对话框的大小和比例；高度指消息记录区的最大高度，超过后滚动显示；距模型距离是气泡底边到模型顶部的空隙（模型高度的百分比，0 为紧贴）
自动隐藏 0 秒表示回复后气泡保持显示
